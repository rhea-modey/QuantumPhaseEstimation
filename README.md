# Quantum Phase Estimation for the Traveling Salesman Problem

A research project exploring quantum phase estimation (QPE) as part of a quantum approach to the **4-city Traveling Salesman Problem**.

The experiments were implemented with Qiskit Aer and evaluated across **50 configurations** using **8,192 shots** per configuration.

This work was presented at the North Carolina Student Academy of Science and received **1st Place in Physics**.
